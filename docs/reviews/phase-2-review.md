Reviewed at 5606f24. Typecheck, lint, 792 tests x3 (no flakes), web build and `wrangler deploy --dry-run` pass. Nothing has run against real Exact.

## Blocking
- B1 Manual sync can never finish on a large division (20 s limit vs ~265 calls at 60/min; resumability only per chunk; full run restarts; bank-account IBAN read repeated every run, even hourly, ~ceil(B/60) calls); hourly incremental starves open items once B > ~7,000; first incremental inserts the whole paid history as closed rows; UI copy "continue where it stopped" is false for full mode. Scheduled full (budget 600) is completable but with 4+ large divisions later ones starve.
  Task: IBAN read out of hourly path (full only / changed relations); reorder so receivables+payables run before bank accounts; resumable list reads or enqueue-and-poll for manual full; don't insert already-closed unknown rows; rotate division start order; fix UI copy; volume tests with page sizes 60 and 1,000.
- B2 Gate refreshes at 540 s but Exact (recollection, unverified) forbids a refresh before ~570 s; a premature-refresh rejection is mapped to needs_reauth and abandons the night's sync.
  Task: margin <= 25 s... i.e. never refresh a token younger than the minimum age; treat premature rejection as retryable (reuse valid token); no forced refresh on 401 if token young; stop mapping token_rejected to needs_reauth; add to ADR 0016 and live checklist.
