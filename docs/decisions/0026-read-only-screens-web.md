# 0026 Read-only screens in the web app (K3a)

Status: accepted. Code: `apps/web/src/{lib,components,pages}`.

- **Number and date locale.** Amounts use nl-NL (`€ 1.234,56`, as in Exact and as Dutch accountants read them); dates use en-GB (`12 Nov 2026`) so they sit naturally in English copy and cannot be misread as month/day. Both locales are constants in `lib/format.ts`. Amsterdam is the display zone for instants; `YYYY-MM-DD` calendar dates are never shifted.
- **Money display.** `formatMoney` takes integer minor units (or a `bigint`), builds an exact decimal string with BigInt and hands that string to `Intl.NumberFormat` (v3 keeps every digit), using the currency's exponent from core `currencyScale` (JPY 0, KWD 3). Nothing is divided as a float, so values above 2^53 print exactly when held as `bigint`. A JSON number above 2^53 has already lost precision at `JSON.parse`; the API never sends one (core `money` rejects them). Credits keep the minus sign and add a visually hidden "credit".
- **Never across currencies.** `MoneyByCurrency` stacks one line per currency; no component adds amounts of different currencies. A foreign-currency figure also shows the Exact-stored division-currency amount ("At least" when `dcComplete` is false) and the note "Some items have no amount in EUR yet".
- **Lists have no `freshness`.** `OpenItemListResponse` carries `asOf` but no freshness, so Invoices and Payables show "Balances as of {asOf}" and leave the stale banner to Overview and Approvals. Proposed: add `freshness` to the list response in a later API task.
- **Requests.** Every screen read goes through `useResource` / `useCursorList`: the request is aborted when the key (division, filters, sort) changes or the screen unmounts, state of another key is never shown (no flash of the old division), a cursor only goes back with the key it came from, and "Load more" is one request however often it is clicked. Identical concurrent reads are not shared across components (none exist); this is deliberate.
- **Keyboard.** Rows have one real button (Tab, Enter, Space). J and K move focus between row buttons, Enter opens the selection when focus is on the page; the handler is off while typing in an input or while a dialog is open. Escape and the Close button close sheets; focus returns to the opener.
- **Read-only.** No pay, approve, match or reminder control exists on these screens, not even disabled. The Approvals sheet is built from the row itself (K4 has no detail endpoint).
- **Relation filter.** The item sheet's "Show all items for this relation" sets `relationId` (and `relationName` for the chip label) in the page URL; filters, status, search and sort live in the URL so a view can be shared and the back button works.
